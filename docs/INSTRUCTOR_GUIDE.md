# Kit del instructor

Incluye diagnóstico, secuencias de 12/24/48 semanas, checkpoints, bancos por escenario,
rúbrica común, exámenes por rol y defensa final. El docente debe separar demostración local,
sandbox y afirmaciones de producción; revisar evidencia antes de evaluar conclusiones; y
rotar fallos, presupuestos y restricciones para evitar respuestas memorizadas.

## Modalidades

| Modalidad | Ritmo | Selección |
|---|---:|---|
| Bootcamp | 24 semanas | fundamentos + proveedor + plataforma + capstone |
| Académica | 48 semanas | 24 partes completas |
| Profesional | flexible | diagnóstico + especialización + defensa |
