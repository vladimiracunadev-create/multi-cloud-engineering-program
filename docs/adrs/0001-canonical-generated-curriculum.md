# ADR 0001: currículo generado desde una fuente canónica

**Estado:** aceptado. **Decisión:** mantener títulos, partes y metadatos en Python estructurado;
generar clases, catálogo y portal; validar que no exista divergencia. **Consecuencia:** los cambios
masivos son revisables y reproducibles, pero requieren ejecutar los generadores.
