# Politica de seguridad

## Versiones mantenidas

La rama `main` es la unica version mantenida. El programa es educativo y sus laboratorios
base se ejecutan localmente sin credenciales ni provisionamiento cloud.

## Reportar una vulnerabilidad

No publiques secretos, credenciales ni detalles explotables en un issue. Usa la opcion
**Report a vulnerability** de GitHub Security Advisories en este repositorio. Incluye el
archivo afectado, impacto, pasos minimos de reproduccion y una mitigacion sugerida.

## Alcance

Se consideran reportes validos los relacionados con el CLI, los generadores, el portal y
los laboratorios. Los ejemplos no prueban cumplimiento ni seguridad de produccion y deben
adaptarse a la cuenta, organizacion y modelo de amenazas de cada implementacion.
